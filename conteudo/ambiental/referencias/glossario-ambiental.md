# Glossário — Ambiental

| Termo | Significado |
|---|---|
| **Acero** | Faixa limpa de vegetação para conter o fogo |
| **ADA** | Ato Declaratório Ambiental (IBAMA), usado no ITR |
| **ANA** | Agência Nacional de Águas — outorga em rios da União |
| **ANM** | Agência Nacional de Mineração |
| **ANPP** | Acordo de Não Persecução Penal |
| **APA** | Área de Proteção Ambiental — unidade de conservação (≠ APP) |
| **APP** | Área de Preservação Permanente |
| **Área consolidada** | Área com ocupação humana anterior a 22/07/2008 |
| **ASV** | Autorização de Supressão de Vegetação |
| **CAR** | Cadastro Ambiental Rural |
| **Central do Proprietário** | Área do SICAR para acompanhar o CAR |
| **CONAMA** | Conselho Nacional do Meio Ambiente |
| **Contra-fogo** | Fogo ateado do acero em direção ao incêndio para eliminar o combustível |
| **CRA** | Cota de Reserva Ambiental |
| **CTF/APP** | Cadastro Técnico Federal de Atividades Potencialmente Poluidoras (IBAMA) |
| **CTF/AIDA** | Cadastro Técnico Federal de Atividades e Instrumentos de Defesa Ambiental |
| **LP / LI / LO** | Licenças Prévia, de Instalação e de Operação |
| **MF** | Módulo fiscal |
| **MRA** | Módulo de Regularização Ambiental (SICAR-SP) |
| **Outorga** | Autorização de uso de recursos hídricos |
| **Pousio** | Interrupção de até 5 anos do uso para recuperar o solo |
| **PRA** | Programa de Regularização Ambiental |
| **PRAD** | Projeto de Recuperação de Área Degradada |
| **Propter rem** | Obrigação que acompanha o imóvel |
| **RL** | Reserva Legal |
| **Servidão ambiental** | Cessão do excedente de vegetação para outro imóvel |
| **SICAR** | Sistema Nacional do CAR |
| **SISNAMA** | Sistema Nacional do Meio Ambiente |
| **TAC** | Termo de Ajustamento de Conduta |
| **TC** | Termo Circunstanciado |
| **TCFA** | Taxa de Controle e Fiscalização Ambiental (IBAMA) |
| **TCPRA** | Termo de Compromisso do PRA |
| **TCRA** | Termo de Compromisso de Recuperação Ambiental |
| **UC** | Unidade de Conservação |
