# Siglas — Cadastros

| Sigla | Significado | Onde / para quê |
|---|---|---|
| **ADA** | Ato Declaratório Ambiental | IBAMA; deduzir áreas ambientais do ITR (dispensado se houver CAR válido) |
| **CAFIR** | Cadastro de Imóveis Rurais | Receita Federal; base do ITR |
| **CAR** | Cadastro Ambiental Rural | Órgão ambiental estadual / SICAR |
| **CCC** | Cadastro Centralizado de Contribuintes | Consulta nacional de inscrições estaduais por CPF/CNPJ |
| **CCIR** | Certificado de Cadastro de Imóvel Rural | INCRA; exigido para vender, desmembrar, arrendar, hipotecar, partilhar |
| **CIB** | Cadastro Imobiliário Brasileiro | Número do imóvel na Receita (= antigo NIRF) |
| **CNAE** | Classificação Nacional de Atividades Econômicas | Atividades da inscrição estadual (até 3 para produtor) |
| **CNIR** | Cadastro Nacional de Imóveis Rurais | Integra INCRA e Receita; vinculação código INCRA ↔ CIB |
| **CNM** | Código Nacional de Matrícula | Número nacional único da matrícula |
| **DCR** | Declaração para Cadastro de Imóveis Rurais | Formulário eletrônico do INCRA (via gov.br) |
| **GUT / GEE** | Grau de Utilização da Terra / Grau de Eficiência na Exploração | Índices de produtividade |
| **NIRF** | Número do Imóvel na Receita Federal | Nome antigo do CIB |
| **SICAR** | Sistema Nacional de Cadastro Ambiental Rural | Integra os CARs |
| **SIGEF** | Sistema de Gestão Fundiária | INCRA; certificação do GEO (não atualiza o SNCR sozinho) |
| **SINTEGRA** | Sistema Integrado de Informações sobre Operações Interestaduais | Consulta de inscrição estadual por CNPJ ou número |
| **SNCR** | Sistema Nacional de Cadastro Rural | Sistema do INCRA (ambiente do analista) |
| **UA** | Unidade animal | Lotação de pastagem no cálculo de produtividade |

**Código do imóvel rural** — número que o imóvel recebe no INCRA ao ser cadastrado; não
é o número do CCIR.

**Posse a justo título** — posse com documento que pode (ou poderia) ser registrado.

**Posse por simples ocupação** — posse sem documento algum.

**Pessoa temporária (DCR)** — arrendatário, parceiro ou comodatário cadastrado no CCIR
do proprietário.
