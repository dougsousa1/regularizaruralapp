# Benefícios Fiscais Estaduais — Exemplos

> **Conferir antes de usar:** benefícios mudam com frequência (inclusive com a reforma
> tributária). A lista abaixo reproduz os exemplos da aula de 2025. Para outros estados,
> consulte a Secretaria da Fazenda.

| Estado | Benefícios citados |
|---|---|
| **RS** | Fim do "fator de fruição" em 2025 (os 15% de créditos retidos passam ao produtor); isenção de ICMS para agroindústrias familiares (+ selo Sabor Gaúcho, feiras, assistência técnica); redução de ICMS para associações hídricas rurais; anistia/renegociação para atingidos pelas enchentes (perdas acima de 30%); NF-e obrigatória |
| **RJ** | Isenção de ICMS na energia elétrica (consumo até 1.000 kWh/mês); redução de base de cálculo; crédito rural facilitado |
| **SP** | Isenções e bases reduzidas em operações específicas; crédito outorgado/presumido; incentivos prorrogados até 2026 para 17 cadeias (mudas, plantas ornamentais, borracha, trigo, ovos, aves, pecuária de corte, hortifrutigranjeiros, algodão...); crédito com bônus de adimplência |
| **SC** | Crédito presumido de até 4% para certos produtos; base reduzida para cesta básica (arroz, feijão, farinha de trigo); subsídio de juros; isenção para agroindústria familiar; emissor de NF-e gratuito |
| **PR** | Isenção de ICMS para hortifrutícolas in natura (exceto para industrialização), vendas para merenda escolar, ovos, mudas, reprodutores e matrizes, diesel de embarcações pesqueiras, importação de máquinas agrícolas sem similar nacional |
| **MT** | Programas estaduais de incentivo (PRODEIC), programa para o algodão, ICMS ecológico, desoneração de exportações |
| **BA** | Programa estadual de incentivo (PF e PJ); isenção para produtos com selo da agricultura familiar; apoio à regularização fundiária; incentivos à irrigação |
| **MA** | Benefícios para soja e milho; tratamento simplificado para agricultura familiar; declaração de conformidade para propriedades até 4 módulos fiscais; incentivos à conservação ambiental; benefício de IPVA |
