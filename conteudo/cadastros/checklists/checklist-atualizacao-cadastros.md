# Checklist — Atualização dos Cadastros

## Qual foi a mudança?
- [ ] Venda total → aquisição de área total
- [ ] Venda parcial/desmembramento → novo CCIR por desmembramento + atualização da área remanescente
- [ ] Compra de área vizinha → anexação de área
- [ ] Inventário/partilha, extinção de condomínio, extremação → mudança de condomínio / novos cadastros
- [ ] GEO averbado / retificação → atualizar área no SNCR (SIGEF não atualiza sozinho)
- [ ] Mudança de exploração (ex.: pecuária → lavoura)
- [ ] Casamento, divórcio, mudança de nome, CPF errado

## Onde atualizar
- [ ] **CNIR primeiro:** imóvel vinculado ao CIB? Se não, vincular
- [ ] **DCR/INCRA:** pedido correspondente + documentos
- [ ] **Receita:** com o vínculo, reflete no CAFIR/CIB; sem vínculo, tratar no CNIR/e-CAC
- [ ] **CAR:** retificar perímetro, titular, áreas
- [ ] **Inscrição estadual:** titulares, matrículas, datas de posse, encerramento
- [ ] **ITR:** próxima declaração com os dados novos

## Conferência final
- [ ] Matrícula, CCIR, CAFIR, CAR e ITR com a mesma área e o mesmo titular
- [ ] Comprovante do CAFIR "ativo"
