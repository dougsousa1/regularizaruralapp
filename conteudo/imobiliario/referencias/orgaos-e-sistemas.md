# Órgãos, Sistemas e Ferramentas

## Federais

| Órgão / sistema | Para quê |
|---|---|
| **INCRA** | Autarquia federal: cadastro rural, georreferenciamento, reforma agrária, regularização fundiária em terras da União |
| **SNCR** | Sistema Nacional de Cadastro Rural → emite o **CCIR** |
| **SIGEF** | Certificação do georreferenciamento (desde 2013); fiscalização de parcelas em glebas públicas |
| **SNCI** | Sistema anterior de certificação (base ainda usada para checar sobreposição) |
| **PGT** | Plataforma de Governança Territorial — porta única dos serviços do INCRA (CCIR, titulação, liberação de cláusula, CCU→TD) |
| **SEI** | Processo eletrônico interno do INCRA; advogado pode ser **usuário externo** |
| **Acervo Fundiário do INCRA** | Login gov.br; **i3Geo**, download das bases (SIGEF, SNCI, assentamentos, glebas), consulta de parcelas por CPF |
| **Receita Federal — CAFIR** | Cadastro do imóvel rural na Receita → **CIB** (antigo **NIRF**, mesmo número) |
| **Conselho de Defesa Nacional (CDN)** | Assentimento prévio para atos na **faixa de fronteira** |
| **SPU** | Patrimônio da União (terrenos de marinha e reservados, terras públicas) |
| **FUNAI** | Terras indígenas (análise de sobreposição) |
| **ICMBio** | Unidades de conservação federais (análise de sobreposição) |
| **Fundação Palmares** | Territórios quilombolas |

## Registro de imóveis

| Ferramenta | Para quê |
|---|---|
| **RI Digital / SAEC (ONR)** | Pedir certidões e visualização de matrícula online |
| **Mapa da ONR** | Mapa dos registradores (serventia e matrícula de imóveis mapeados) — exige cadastro |
| **Código de Normas da Corregedoria** (site do TJ do estado; em SP, "Normas da Corregedoria") | Regras de cada procedimento no estado — **leitura obrigatória** para advogados, engenheiros e agrimensores |
| **Código Nacional de Normas (Provimento CNJ 149/2023)** | Regras nacionais do extrajudicial |

## Ferramentas públicas de pesquisa

- **QGIS** — software gratuito para cruzar bases (localizar o cliente em assentamento,
  gleba federal ou estadual).
- **Google Earth Pro** — imagens históricas.
- **SICAR** — Cadastro Ambiental Rural (alguns estados têm sistema próprio: PA, MT, AM).
- **MapBiomas** — uso do solo e desmatamento ao longo do tempo.
- Base de **florestas públicas tipo B** (MMA).
- **Embrapa** — tabela de módulos fiscais e FMP por município.
